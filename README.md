# JEET.NAG — Portfolio Website

Official portfolio website of **Jeet Nag**, AI Video Creator, Video Editor, Motion Designer & Cinematographer based in Bangalore, India.

## Features

- **Cinematic Sequence Aesthetics**: Modeled on modern video studio design language featuring dark monochrome aesthetics, vivid red accents (`#dc2626`), and NLE editor inspired details.
- **Scroll-Driven Timeline Rulers**: Animated playhead scrubber that tracks viewport scroll progress across the editing timeline.
- **Dual Work Layouts**: Instant switching between interactive **Poster Reel** view and an **EDL Table (Edit Decision List)** view.
- **Responsive Video Player Modal**: Seamlessly embeds YouTube showcase videos and 9:16 Instagram Reels with proper aspect ratio preservation.
- **Production Capabilities**: 4-stage interactive accordion pipeline breakdown with detailed deliverables, turnaround times, and specs.
- **Experience Timeline**: Career history covering GRX10 Solutions, SK Photography Studio, Josh Talks, Keyline Digitech, and Creative Memories.
- **Technical Arsenal**: Categorized tools and workflows across Veo 3, Runway Gen-3, Kling 3.0, ComfyUI, Premiere Pro, and After Effects.
- **Sequence Full-Screen Navigation**: Modal overlay with direct collaboration card, email copy interaction, and social links.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Icons**: Lucide React + Custom Inline SVGs
- **Typography**: Syne, Space Grotesk, JetBrains Mono

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
